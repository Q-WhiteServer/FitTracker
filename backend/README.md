# Backend API FitTracker

Proyek backend API untuk aplikasi pelacak kebugaran (FitTracker) menggunakan Node.js, Express, dan MySQL.

## Cara Menjalankan:
1. Import file `skema.sql` ke dalam database phpMyAdmin (buat database bernama `db_fittracker`).
2. Duplikat file `.env.example` menjadi `.env` dan sesuaikan konfigurasinya.
3. Buka terminal di folder ini, lalu jalankan perintah: `npm install`
4. Jalankan server dengan perintah: `node server.js`
